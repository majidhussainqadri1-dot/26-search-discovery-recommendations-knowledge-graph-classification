# Operations

Named responsibilities: Search Product Owner, Search/Relevance Engineer, Taxonomy Curator, domain reviewers, Privacy/Safety reviewer, release operator and incident escalation owner.

Dashboards and reports cover connector health/lag, jobs/dead letters, document counts, zero-result metrics, tombstone backlog, graph integrity and active policy version. Runbooks cover connector outage, private leakage, bad taxonomy merge, ranking regression, index corruption, provider outage and deletion backlog.

Cadence: weekly relevance/zero-result review; monthly safety/privacy/bias review; quarterly connector/retention/restore drill; every release compares golden sets and retains evidence.
