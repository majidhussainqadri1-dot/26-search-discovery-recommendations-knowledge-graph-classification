# Software Bill of Materials

Runtime dependencies:

- WordPress Core APIs (GPL-2.0-or-later)
- PHP 7.4+ standard library
- Browser Fetch API and WordPress Dashicons

No bundled third-party PHP/JavaScript libraries, remote fonts, trackers, vector SDKs or external CDN assets are included. Any future external search/vector provider requires a separately approved adapter, data-processing terms, regional/privacy assessment, secret management and exit/rebuild plan.
