# Rollback

Triggers include private leakage, critical relevance/safety regression, stale deletion, connector contract break, queue corruption, latency saturation or accessibility blocker.

1. Disable `activated` and personalization; public surfaces show honest unavailable/degraded states.
2. Suspend affected connector or roll back ranking policy.
3. Stop reindex jobs and preserve audit/tombstone evidence.
4. Re-enable prior owner-native/legacy search route through File 20 if approved.
5. Restore File 26 database/config from verified pre-release backup only in an isolated rehearsal first.
6. Reconcile owner state, tombstones, caches, nodes and edges before reopening.
7. Record incident, cause, corrected tests and Founder decision.

Uninstall is non-destructive by default; purge is not implemented as an ordinary uninstall path.
