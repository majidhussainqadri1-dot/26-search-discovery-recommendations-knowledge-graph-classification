Federated privacy-safe search, discovery, recommendations, taxonomy, knowledge graph and classification for the Sabri Social Homeopathy Platform.

== Description ==
File 26 is a derivative indexing and retrieval service. Canonical owners retain all domain write authority. Activation is fail-closed until approved connectors and staging gates are complete.

== Installation ==
1. Install the package on staging.
2. Register owner-signed connector manifests.
3. Run shadow reindex, reconciliation and security/privacy tests.
4. Enable Approved runtime activation only after acceptance.
